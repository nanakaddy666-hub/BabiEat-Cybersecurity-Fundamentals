## Project Objective
This project serves as a comprehensive foundation in cybersecurity fundamentals, specifically tailored for the **BabiEat** food delivery ecosystem. The goal is to move beyond theory and implement security measures that protect customers, restaurants, and drivers across West Africa.

## Core Pillars (The CIA Triad)
Every task in this repository is designed to support one of the three pillars of security:
*   **Confidentiality:** Protecting user data (Addresses, Payment Nicknames) via Encryption.
*   **Integrity:** Ensuring order details aren't tampered with using Hashing and Digital Signatures.
*   **Availability:** Maintaining system uptime during peak delivery hours through Network Security.
